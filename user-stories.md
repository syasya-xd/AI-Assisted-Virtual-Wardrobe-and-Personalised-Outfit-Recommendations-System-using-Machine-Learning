# User Stories

1. As a user, I want to add and organise my clothing items in a digital wardrobe, so that I can easily manage and view the clothes I own.
2. As a user, I want to receive personalised outfit recommendations based on my clothing, preferences, occasion, and colour compatibility, so that I can choose suitable outfit combinations more easily.
3. As a user, I want to review and save recommended outfit combinations, so that I can reuse my preferred outfits in the future.
