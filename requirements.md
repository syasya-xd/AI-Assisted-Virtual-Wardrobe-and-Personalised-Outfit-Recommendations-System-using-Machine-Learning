# Requirements

## Functional requirements 
1. The system shall allow users to add clothing items by capturing or uploading clothing images and storing them in their digital wardrobe.
2. The system shall automatically classify uploaded clothing items into predefined categories such as tops, bottoms, dresses, shoes, and accessories, and allow users to review or correct the classification.
3. The system shall allow users to provide personal preferences, including preferred colours, styles, and occasions, for personalised outfit recommendations.
4. The system shall analyse clothing compatibility and colour characteristics, including skin-tone-aware colour compatibility, to generate suitable outfit combinations from the user's digital wardrobe.
5. The system shall generate and rank personalised outfit recommendations using the proposed hybrid recommendation algorithm and allow users to save their preferred outfit combinations

## Non-functional requirements 
1. The system shall display the result of a clothing classification request within 5 seconds under normal network and device conditions.
2. The system shall generate personalised outfit recommendations within 5 seconds after the user submits the recommendation criteria.
3. The system shall provide an easy-to-use mobile interface that allows users to complete common tasks, such as adding clothing and viewing recommendations, with minimal navigation.
4. The system shall protect users' personal information and clothing images from unauthorised access.
5. The system shall provide consistent recommendation results when the same wardrobe, user preferences, and recommendation criteria are provided under the same system conditions.
