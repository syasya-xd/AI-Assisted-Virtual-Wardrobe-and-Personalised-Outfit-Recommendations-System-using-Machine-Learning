# AI Assisted Virtual Wardrobe and Personalised Outfit Recommendations System using a Hybrid Recommendation Algorithm
This project is to solve the difficulty individuals face in managing their existing wardrobe and selecting suitable outfit combinations. This happens as users may have many clothing items but still struggle to decide what to wear because they need to consider compatibility, personal preferences, occasion and colour suitability. Therefore, I propose an AI-assisted virtual wardrobe that organises their clothing and provides personalised outfit recommendations based on their own wardrobe and preferences.

## Problem statement
Individuals with personal clothing collections may experience difficulty organising their clothes and selecting suitable outfit combinations. They may spend considerable time deciding what to wear because they need to consider clothing compatibility, personal preferences, occasions, and colour suitability. Existing general fashion recommendations may not always reflect an individual's own wardrobe and personal characteristics, resulting in less relevant outfit suggestions. Therefore, there is a need for an AI-assisted system that can organise users' clothing and provide personalised outfit recommendations based on their own wardrobe and preferences.
